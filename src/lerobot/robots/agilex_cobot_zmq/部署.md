# AgileX ZMQ 部署

真机只做 ROS 和 ZMQ 的转换。3090 加载 FineART，通过 ZMQ 收观测、发关节目标。先起真机，再起推理。

## 拷什么

真机只拷这一个目录：

`lerobot/src/lerobot/robots/agilex_cobot_zmq/`

3090 拷这三样：

- `lerobot` 当前工作区。ZMQ 改动还没提交，不要重新 clone。
- `pretrained_model`（zip tie 检查点，约 8.8 GB）
- `paligemma-3b-pt-224`（约 11 GB）。本机已经有一份：`/media/jy/HIKVISION/3090交接/lerobot/pretrain_model/paligemma-3b-pt-224`。这不是单独的小词表，是完整的 PaliGemma 3B 权重。H20 容器里的同一份在 `/workspace/lerobot/pretrain_model/paligemma-3b-pt-224`。检查点里写的是这个容器路径，3090 上用下面的 `TOKENIZER_PATH` 指到拷过去的目录。

## 环境

真机：现有 ROS1、Python 3.8。先 `source` ROS。手臂和三路相机的原驱动先开着。额外安装 `pyzmq`（`pyzmq>=26.2.1,<28`）。`cv_bridge`、OpenCV、`numpy`、`scipy` 沿用原来的 ROS 环境。不需要 GPU，不需要 `lerobot-h20`。

3090：和 H20 训练对应的 Python 3.12 环境（PyTorch、transformers）。

## 启动

真机（一键，会 source ROS / workspace、设 `ROS_IP`、检查 master）：

```bash
# 先保证 roscore 或原 bringup 已起（手臂 + 相机驱动）
bash start_bridge.sh
# 等价于: bash start_bridge.sh --bind-host=0.0.0.0
```

改 IP 或 master 时：

```bash
ROS_IP=192.168.1.139 ROS_MASTER_URI=http://127.0.0.1:11311 bash start_bridge.sh
```

监听 `5600`（关节指令）、`5601`（观测）、`5602`（复位）。

3090，在 `lerobot-h20` 根目录：

```bash
scripts/run_inference_zmq.sh
```

脚本里已经写了 `POLICY_PATH=/home/xlk/work/lerobot/checkpoints/fineart-vla`、`ROBOT_IP=192.168.1.139`、`TOKENIZER_PATH=/home/xlk/work/lerobot/pretrain_model/paligemma-3b-pt-224`。

这个脚本跑 zip tie 的 FineART，trained RTC，交互模式。策略加载并复位后机械臂不动。终端里先 `/autosteer Pick up zip tie, then thread its tail through the lock.`，再 `/start`。要自己给指令就用 `/subtask <instruction>` 再 `/start`。`/stop` 结束。3090 要能访问真机的三个端口。
