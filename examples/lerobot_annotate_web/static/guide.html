设计

LeRobot 仓库里的官方入口是命令行 lerobot-annotate，没有自带网页。这个页面放在 examples/lerobot_annotate_web，调用同一套计划、插话、计划更新、VQA、校验和写回，不另做一套字段。

  • 持续列 language_persistent：subtask、plan、memory、task_aug、motion。官方模块会写前四种，motion 只在人工编辑里添加。
  • 事件列 language_events：interjection、vqa、trace，以及 style 为空、带 say 工具调用的说话事件。页面上说话显示成 say，保存时写成官方工具调用。
  • 图像、state、action、原来的任务句保持不动。第一次覆盖写入前，把 meta/info.json 和 data parquet 复制到 meta/backup_before_language/。
  • 生成新数据集时，复制 meta 和 parquet，视频用符号链接指回原文件，避免再拷一遍几百 MB 的 mp4。
  • 模型是 DashScope 的 qwen3.8-max，OpenAI 兼容接口。密钥从环境变量 DASHSCOPE_API_KEY 或 annotate-tools/annotator/.env 读取，页面和日志都不打印密钥。
  • 已经写好的 .annotate_staging/episode_XXXXXX/<module>.jsonl 会跳过，中断后重新跑同一条命令会从缺的情节继续。DashScope 若把某一帧误判为不适宜内容，这一次调用记一条警告并跳过，整次任务不会因此退出。

画面沿用 annotate-tools 可视化那套：Space Grotesk 和 Noto Sans SC，深色底，橙色主按钮，青色小标题。

安装

在已经装好 LeRobot 的环境里执行。这台机器用的是 conda 环境，uv 不在 PATH 上。

cd /home/xlk/work/lerobot
/home/xlk/miniconda3/envs/lerobot/bin/python -m pip install 'openai>=1.40,<2.0'

密钥二选一。不要把密钥写进网页或提交到 git。

export DASHSCOPE_API_KEY=你的密钥
# 或者保持这个文件存在，启动时会自己读：
# /home/xlk/work/annotate-tools/annotator/.env

可选环境变量：FINEART_VLM_MODEL 换模型名，DASHSCOPE_BASE_URL 换兼容接口地址，FINEART_ANNOTATE_ENV 指向另一份 .env。

启动和退出

网页只监听本机。

cd /home/xlk/work/lerobot
PYTHONUNBUFFERED=1 /home/xlk/miniconda3/envs/lerobot/bin/python examples/lerobot_annotate_web/app.py

浏览器打开 http://127.0.0.1:8766/。说明页是 http://127.0.0.1:8766/guide。

退出网页：在启动它的终端按 Ctrl+C。这只停 HTTP 服务。自动标注是另一个进程，停网页不会把它停掉，已经跑完的暂存还在数据集的 .annotate_staging/。

要停掉标注进程，先在「自动标注」页看 pid，再执行 kill <pid>。不要对数据集 parquet 做强制删除。覆盖写入使用临时文件替换，中途杀掉可能留下 .parquet.tmp，正式的 parquet 仍是上一版。

命令行等价启动，不经过网页：

/home/xlk/miniconda3/envs/lerobot/bin/python examples/lerobot_annotate_web/run_pipeline.py \
  --root /home/xlk/work/data/huggingface/lerobot/take_me_tissues_v30 \
  --episodes all \
  --mode overwrite

只标第 0 条并写到新目录：

/home/xlk/miniconda3/envs/lerobot/bin/python examples/lerobot_annotate_web/run_pipeline.py \
  --root /home/xlk/work/data/huggingface/lerobot/take_me_tissues_v30 \
  --episodes 0 \
  --mode copy \
  --output /home/xlk/work/data/huggingface/lerobot/take_me_tissues_v30_annotated

take_me_tissues_v30 全流程

数据集在 /home/xlk/work/data/huggingface/lerobot/take_me_tissues_v30。v3.0，30 fps，28 条轨迹，54610 帧，三路视频 observation.images.high、left、right，动作和状态都是 16 维。任务句是：Please take a pack of tissues from the drawer next to you, then pull out one sheet and give it to me.

  1. 按上面的命令启动网页，打开 http://127.0.0.1:8766/ 。右上角应变成「已连接」。
  2. 路径保持该数据集，点「加载」。数据集页应出现 v3.0、54610 帧、三个视频特征和 data/、videos/、meta/ 文件表。点开特征字典能看到 action、observation.state 的 shape。
  3. 打开「回放」，点 #0。三路画面同时出来。用播放、暂停和速度（0.25× 到 4×）控制，拖动进度条时三路一起跳。第 0 条高位相机在拼接视频里从 0 秒到 79.6 秒。
  4. 打开「表格」，文件选 data/chunk-000/file-000.parquet，episode 选 0。表格里是帧行，action 显示成向量摘要。点一行，下面的字典展开这一行。
  5. 打开「自动标注」。示例按钮会填入情节：all、0、0-2、0,3,5。特征默认全选。只要 subtask 和 memory 时，点「只要 subtask + memory」，plan、task_aug、interjections 和 vqa 不会调用模型。插话会连同 say 一起生成。覆盖原数据集会改当前 parquet；生成新数据集则把结果写到路径框里的目录，默认是原目录名加 _annotated。新目录若已存在会拒绝，避免盖掉上次结果。命令行对应 --features subtask,memory。
  6. 自动标注由「开始」「暂停」「继续」「结束」控制。任务一旦起来，「开始」会锁住，暂停和结束可以点；继续只有暂停之后才亮。按钮正下方是当前第几条、本条已等待多久，以及最新日志，模型还没返回时秒数也会往上走。暂停冻住当前模型调用，继续从原地接着跑，结束停掉进程并保留暂存。勾选的每个特征都有自己的进度。所选情节里这些特征的暂存都齐了，页面会用绿色提示「所选特征已标注完成」；语言列还没进 parquet 时，同一句会说明还要再点「开始」才会写入。页面上的表按 episode、style、将写入的语言列和句子列出已经生成的内容；action、state 和图像在任务结束前不会改，语言列要等写回 parquet 后才变成「已写入」。
  7. 全部阶段结束并校验通过后，语言列才写入 parquet。覆盖模式下重新点「加载」，语言列状态变为已有。生成模式下把路径改成新目录再加载。然后在回放里点 subtask 句子，视频会跳到对应时间。
  8. 打开「人工编辑」，选同一条。改 subtask 文字，或「添加事件」写一句 interjection。vqa 和 trace 必须填相机名，例如 observation.images.high。点「保存这一条」。只改这一条，其它 episode 保留。再点该条，表格和编辑区应显示刚保存的句子。
  9. 标注还在写整表时不要保存。写回和人工保存会抢同一个 parquet。
